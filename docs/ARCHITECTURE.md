# Pelican Mods — архитектура и план

Ланчер и менеджер модов Stardew Valley для macOS (arm64). Tauri 2 + Vue 3 + shadcn-vue (reka-ui) + Tailwind 4, Rust-бэкенд, C#-компаньон для SMAPI.

## Окружение (проверено на этой машине)

- Игра: `/Applications/Stardew Valley.app`, версия 1.6.15.24356, .NET 6, файлы в `Contents/MacOS`.
- SMAPI не установлен, папки `Mods` нет, сохранений в `~/.config/StardewValley/Saves` пока нет.
- Тулчейн: Node 26, Rust 1.99.

### Ключевые решения

- **Встраивание в игру** — свой SMAPI-мод `PelicanCompanion`, который едет внутри приложения и линкуется в каждый профиль. Сервер WebSocket держит ланчер: случайный порт на loopback и токен, которые попадают в игру через `PELICAN_COMPANION_URL`; мод сам подключается и переподключается. Сообщения — JSON с полем `type`, версия протокола приходит в `hello`; формы описаны в `companion/PelicanCompanion/Protocol.cs` и `src-tauri/src/companion.rs` и меняются парой.
- **Без ссылок на игру** — компаньон собирается только против `StardewModdingAPI.dll` и Newtonsoft из SMAPI, а состояние игры читает через рефлексию. Поэтому CI собирает его из релиза SMAPI (`scripts/smapi-refs.sh`), без установленной игры.
- **GMCM изнутри** — схему настроек мод не отдаёт, поэтому компаньон читает внутренние классы GMCM по именам, а ключ `config.json` каждой опции восстанавливает по IL её геттера. Применение настроек повторяет кнопку «Сохранить» GMCM; для модов без GMCM конфиг перечитывается в живой объект мода.
- **Обновления модов** — `UpdateKeys` из `manifest.json` → пакетный запрос к публичному `smapi.io/api/v3.0/mods` (покрывает Nexus/GitHub/ModDrop/CurseForge без ключей). Nexus API v1 — для деталей, файлов и changelog.
- **Скачивание с Nexus** — регистрация обработчика `nxm://` (tauri-plugin-deep-link), API-ключ в Keychain. Premium — прямые ссылки из API, иначе через кнопку «Mod Manager Download» на сайте.
- **Профили модов** — моды хранятся в собственном хранилище `~/Library/Application Support/Pelican/mods/<id>@<version>`, а в `Mods/` игры раскладываются симлинками активного профиля. Переключение профиля = пересборка симлинков, без копирования. SMAPI поддерживает `--mods-path`, так что игровую папку можно вообще не трогать: запуск идёт с `--mods-path <profile-dir>`.
- **Настройки модов** — два источника схемы: (1) GMCM-регистрации, которые компаньон отдаёт из запущенной игры и кэширует в SQLite; (2) вывод типов из `config.json`, если схемы нет. Изменения пишутся в `config.json`; если игра запущена — применяются через компаньон.
- **Сохранения** — Rust-парсер XML (quick-xml) для превью и прогресса; бэкап перед запуском игры и перед обновлением модов; экспорт/импорт `.zip`.
- **Расширяемость** — внутренний реестр «модулей» (UI-маршрут + Rust-команды + опционально RPC-методы компаньона). Прогресс прохождения и редактор фермы будут модулями. Для карт — рендер тайлов из распакованного `Content` (xnb → png через встроенный распаковщик, по образцу StardewXnbHack) на canvas/PixiJS.

## Структура репозитория

```
app/            Vue-фронтенд (src/, components/ui — shadcn-vue)
src-tauri/      Rust core (crates по слоям выше)
companion/      C# SMAPI-мод (net6.0) и его xunit-тесты
docs/
```

## Этапы

1. **Каркас.** Tauri + Vue + shadcn-vue, тема «уютный гибрид», i18n RU/EN, навигация. Поиск игры, установка SMAPI (скачивание релиза с GitHub, запуск установщика), запуск игры через SMAPI.
2. **Библиотека.** Чтение `manifest.json`, зависимости, включение/выключение, установка из zip, профили на симлинках/`--mods-path`.
3. **Обновления.** smapi.io API, бейджи, обновление одной кнопкой с бэкапом.
4. **Источники.** Nexus (ключ, поиск, карточка с описанием/скриншотами/файлами, nxm://), GitHub Releases, ModDrop, CurseForge.
5. **Сохранения.** Список ферм, превью, бэкапы, экспорт/импорт.
6. **Компаньон.** C#-мод, WS-протокол, live-состояние, GMCM-схемы, применение настроек в рантайме.
7. **Настройки модов.** Форма по схеме, редактор JSON как fallback.
8. **Модули.** Прогресс прохождения, затем редактор фермы.

Каждый этап закрывается сборкой, тестами (vitest, cargo test, xunit для компаньона) и линтерами.
